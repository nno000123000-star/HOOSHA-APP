هوشا — نسخهٔ iPhone و ویندوز (PWA)
================================

این پوشه همان برنامهٔ هوشا ۲.۹.۱ است که از مرورگر نصب می‌شود (بدون Apple Developer و رایگان).

۱) ساخت آدرس اینترنتی رایگان (GitHub Pages)
  - در GitHub یک مخزن تازه بساز: نام hoosha-app ، نوع Public.
  - Add file ← Upload files ← همهٔ فایل‌های همین پوشه را بکش: index.html ، sw.js ، manifest.webmanifest و پوشهٔ icons ← Commit changes.
  - Settings ← Pages ← Source: Deploy from a branch ← Branch: main و پوشهٔ / (root) ← Save.
  - بعد از ۱ تا ۲ دقیقه آدرس برنامه این می‌شود:  https://نام-کاربری-تو.github.io/hoosha-app/

۲) نصب روی iPhone
  - آدرس را فقط در Safari باز کن.
  - دکمهٔ Share ← Add to Home Screen ← Add.
  - آیکن «هوشا» روی صفحهٔ اصلی می‌آید و مثل برنامه باز می‌شود.

۳) نصب روی ویندوز
  - آدرس را در Edge یا Chrome باز کن.
  - در نوار آدرس روی آیکن نصب (⊕ یا «Install») بزن؛ یا منو ⋯ ← Apps ← Install this site as an app.
  - برنامه در Start Menu می‌آید و در پنجرهٔ جدا باز می‌شود.

نکته‌ها
  - بار اول اینترنت لازم است؛ بعد از آن برنامه بدون اینترنت هم باز می‌شود.
  - اطلاعات این نسخه جدا از نسخهٔ اندروید است؛ با «پشتیبان‌گیری / بازیابی» در پروفایل می‌توانی منتقل کنی.
  - در iPhone انتخاب پوشه وجود ندارد؛ خروجی‌ها با پنجرهٔ Share/Files ذخیره می‌شوند. در ویندوز (Edge/Chrome) انتخاب پوشه کار می‌کند.
  - برای بروزرسانی، فقط index.html تازه را در همان مخزن جایگزین کن.
